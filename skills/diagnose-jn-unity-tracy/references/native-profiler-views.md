# 原生配图与交互回查（2.3.0）

## 适用范围与实现状态

生成新报告前读取本合同。Query 仍是统计事实权威；Profiler 只提供原生视觉证据和人工探索，不替代常驻 Query MCP 或源码深查。不得为正常分析临时下载 SDK、编译、修补或发布 Profiler。工具开发需另列任务与版本。

2.3.0 在本包中新增的是执行规范。现有 build_report.py / validate_analysis_result.py 并未实现通用 Profiler 加载、定位、导图及下面的展示门禁。不得仅凭它们 passed=true 宣称展示验收通过；额外保存 view-manifest.json、presentation-validation.json 和人类可读展示状态。不要向现有 analysis-result schema、Schema 4 状态机或 Query Profile 填入未支持的字段。固定某帧的实验构建不等于已发布的通用工具。

当前生成器不能嵌入原生图/入口时，可根据展示记录整理独立 Native-Profiler-Views.md 附录，按可读条目名称关联已验证图片、入口或缺口；不手工改写或冒充生成器已支持核心报告布局，也不覆盖冻结报告。presentation-validation.json 另记 report_integration=pending，并在交付中披露主报告集成未完成；未来只有生成器实际支持并验证后才记 complete。

## 每项覆盖与视图选择

- 每个已完成深度观察须有解释该结论所需的原生图片和交互回查入口，或逐项明确的展示缺口。选关键证据视图，不按候选数量机械截图。
- 新 P1 筛选入队项须有已核查代表样本的回查入口或具体缺口；适用的原生图可帮助测试人员决定是否源码深查。不得自动批准，不用 Top N 或图片预算削减候选分流和证据调查。
- 等待类结论的视图应覆盖等待方与实际依赖任务/完成端；屏幕仅显示等待点不足以证明等待来源。必要时多图关联，不把两张相近时间图当作已证明的依赖关系。
- 截图与查看器均保留真实术语。标题、图注、链接显示文字不展示内部身份。图注说明 FrameSet、显示号与索引约定、时间范围、可见线程及未覆盖部分。
- 优先使用 Profiler 原生画面。程序重绘的统计图/关系图只能作为有证据的辅助图，明确标注来源，不能伪称原生截图。采集的 FrameImage、Profiler Canvas 截图、重绘图分别登记。

## 预检与配置

先核对已安装工具版本、构建身份、普通 Trace 格式兼容性、浏览器能力及工具实际暴露的加载/定位/导图接口。只调用已发现的能力，不编造 MCP 方法、命令行参数、地址或成功回执。能力不足记录 capability_missing，继续不依赖展示工具的分析。

Query 分析预算仍唯一来自 JNTracy.AnalysisProfile.yaml。可另存 report-viewer.yaml 记录展示预算和本机已验证工具路径：加载超时、内存上限、视图尺寸、并发限制、图片目录及服务生命周期；这些参数不能改变采集域、候选阈值、Query 统计或源码队列。没有已实现的配置加载器时，将其作为运行记录，由代理明确执行，不宣称工具自动读取。

不得把 Trace 文件大小或录制分钟数当作是否能展示的固定门槛。内存限制须区分 Wasm 线性内存、浏览器其他内存和主机资源；记录实际版本/预算、加载与后台处理耗时、观测峰值及测量范围。不要把最终采样说成峰值，或将单份录制线性外推为支持时长。大文件由本地工具读取，模型只接收必要摘要。

## 定位合同与原生导图

在 view-manifest.json 独立登记 schema_version=1。它是本次新增的展示记录合同，不是声称存在对应 Query API 或现有 JSON Schema 验证器。每条至少保存：

| 机器字段 | 必须保存的内容 |
|---|---|
| view_id、issue_refs、candidate_refs | 机器身份、多对多引用及各条目复用依据 |
| trace_identity、renderer_identity | Trace 强身份与工具构建版本；原始身份只进机器记录 |
| requested_location | FrameSet、Query 帧索引、期望原生显示号、时间范围、线程/事件/Job 身份、关注与相关轨道 |
| resolved_location | 工具实际解析的身份与范围、显示号映射依据、加载/后台就绪/定位回执路径 |
| image | 实际文件、SHA、尺寸、可见范围、截图时机、人工可读性检查、生成/复用状态 |
| viewer | 实际可达入口、能力范围、服务启动/恢复方法及最近交互验证时间 |
| evidence、resources、gaps | 支撑结论的 Query 证据、阶段时间/重试/资源记录、失败原因与下一步 |

截图与链接必须由同一定位记录驱动。先核对 Trace，再解析原生位置，并与 Query 的帧起止时间或事件范围核对。命名 FrameSet 的数组索引与 GUI 显示号分别保存，不假定相等。Query ref 不是 Profiler 内部指针，线程名称也不保证唯一；没有可信解析时不得伪造精确定位。

调用已验证的工具运行时加载指定 Trace，优先复用同一 Trace 的已有查看器；不得为每个报告条目复制/重新打包 Trace 或重新编译网页。跳转到目标时展开相关轨道，仍允许探索其他线程和完整时间范围，不能把其他数据静默删掉。

等待实际后台就绪和定位回执后，由 Profiler 绘制原生视图，再通过工具导出或无界面浏览器导出 Canvas。正常流程不采用桌面点击截图，不由 AI 重绘时间线代替原生画面。导图不是根因证明，数值和关系仍须引用 Query 证据。

## 三类独立验收

在 presentation-validation.json 保存 schema_version=1、每条视图的 required_checks、检查/时间/证据、required_views、passed_views、failed_views、pending_views、report_integration、presentation_status。状态取 complete / degraded / pending；只有全部必需视图的适用检查均通过、主报告集成完成且无待处理项才为 complete。完成的深度观察三类检查均必需；仅供新 P1 决策的回查样本可不配图，此时 image=not_required 并记录理由，不算失败也不强制每个 P1 截图。已承诺或论证所必需的配图不能改为 not_required 来规避失败。

1. 数据与定位：强身份相同，范围和编号映射核对通过；没有以默认帧、仅同名线程或错误实体代替目标。
2. 原生图片：目标与必要关联轨道可见，文字可读，无弹窗遮挡关键内容。导出后实际检查图片；崩溃后最后一张画面不能算通过。异常时间/负数等可疑字段必须调查或标为不可采信，不能用于报告归因，也不能悄悄隐藏后声称全部数值正确。
3. 交互：验证缩放、时间平移、滚动屏幕外轨道、事件选择及操作后仍可响应。检查真实范围/选择状态变化及运行异常；页面 HTTP 200、出现 Canvas 或图片不同均不独立证明可用。允许空闲时停止重绘，以真实输入后的响应判断。链接展示“在 Profiler 中查看”仅限已通过且已核对可达的入口；静态报告链接不能冒充它。

相同已就绪查看器可复用会话级交互检查，但每个跳转仍须核对定位和当前存活状态。程序检查和人工画面检查分别保存，未执行的自动验证不能填写成功。

## 失败、恢复与交付

分别记录 capability_missing、load_failed、identity_mismatch、location_failed、image_failed、interaction_failed、resource_exceeded；不得合并为空数据。相同失败最多做两次有依据的恢复尝试；没有条件变化不重试。工具缺陷保存复现、版本和日志，不在分析中静默修补。

展示失败不推翻已经有效的分析证据，不篡改原 analysis_complete，也不能冒充“全部交付完成”。交付合法分析/阶段结果，单独并列展示状态、缺口和下一步；没有展示验证记录时默认为 pending。不得因截图失败重新扫描、重做已完成源码分析或无限查询。除非用户另行批准，不能裁剪录制、删除采样/线程/域或上传公共服务来规避容量限制。

原生 PNG 独立存放于报告 visuals/assets/native-profiler/，Markdown 使用相对路径，分册共享可移植资源；不嵌入大量 Base64。每个必需条目指向视图或缺口，复用依据逐项可查。图片缓存键包含 Trace、工具版本、定位/轨道/视口及显示配置；版本或参数变化使相关缓存失效，只重做受影响视图。

Markdown 与可选静态 HTML 报告仍可离线阅读；可交互 Profiler 是另一个运行时服务，不能承诺双击 HTML 就能加载 Wasm。只使用实际分配且核验过的地址，不固定某机器路径/端口；交付服务状态、适用浏览器及启动恢复方法。会话关闭后旧 localhost 链接不代表仍可用。默认本地服务，不因生成回查入口恢复此前停用的定时任务。

原生图片保留实测文件 SHA；未验证跨浏览器/设备像素确定性时，不纳入“所有原生 PNG 两次生成必定同 SHA”的承诺。固定分析机器数据与原生运行时产物分开验收。记录展示阶段时间、查询/证据和视图复用、失败次数；模型实际 token usage 不可取得时明确不可获得，不用字数、文件大小或账户额度代替。
