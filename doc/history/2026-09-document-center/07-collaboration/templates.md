# 开发记录与交接模板

> 首版：2026-09-07｜本文为文档中心的维护约定，不自动改变外部任务授权。
> [返回文档入口](../README.md) · [当前状态](../STATUS.md) · [来源索引](../08-references/source-index.md)

以下模板供新任务复制填写。它们是空白记录格式，不代表已开展任务；不要用占位字段生成完成声明。

## 专题/迭代记录

```markdown
# <专题ID>：<问题与目标>

日期/更新时间：
状态：Planned / InProgress / Failed / PassedWithLimits / Accepted
相关仓库、分支、worktree：
基线commit、dirty范围：
配套协议/Schema/Skill：
关联计划、上轮记录：

## 问题与成功标准
触发条件、原行为、目标行为、验收范围：

## 方案与取舍
采用方案、关键备选、为什么选择、重新评估条件：

## 实际改动
模块/文件、语义变化、配置变化、兼容影响：

## 验证
输入/产物SHA、命令、退出码、时间、资源指标：
静态/单元：
契约/真实Trace：
Player/Editor：
性能/稳定性：
原始证据链接：

## 结论与限制
已证明：
未证明：
失败/延期及原因：

## 交接
下一步最小动作：
进入条件：
正在运行的本任务进程身份（若有）：
需要保留的文件与恢复状态：
```

## 单次对话收尾

```markdown
# YYYY-MM-DD-HHMM：<任务ID>

本轮目标：
开始/结束时间与时区：
读取入口：
实际修改文件：
源码/工具/Trace身份：
完成事项与证据：
失败或未完成事项：
对当前系统/分支/工具文档的更新：
下一轮先读：
下一步：
```

## 分支说明

```markdown
# <仓库>/<分支>

用途与非目标：
创建基线、创建原因：
当前HEAD与核对时间：
worktree与tracked/untracked状态：
相对明确基线的主要差异：
配套仓库分支、协议和产物：
已完成验收与例外：
关联设计/实现/报告：
合并/发布状态及实际证据：
后继或归档关系：
```

## 架构决策

```markdown
# ADR-<编号>：<决策名称>

状态与适用版本：
问题与约束：
备选方案：
最终决策：
收益、成本、风险：
验证依据：
受影响模块/契约/工具：
重新评估条件：
替代/被替代决策：
```

## 失败与恢复记录

```markdown
# <Run ID>：失败记录

失败阶段：
输入与工具强身份：
最后成功持久化步骤：
原始错误/回执路径：
已观测资源数值（注明采样时刻，未知不补造）：
取消/结束状态：
已确认事实：
尚待验证假设：
未执行的后续步骤：
下次有界复现目标：
```
