# 本地报告查看器

本阶段只开发工具并生成独立验收页，不更新历史报告。随机抽取 QS17 的一个已完成普通帧观察，排除1324；抽样记录保存在独立验收目录。

组件：标准库 Python 本地只读 HTTP 服务；Wasm64 Profiler 的运行时加载及 JSON 导航桥；原生 Canvas 导出脚本；独立 Markdown 验收页。服务绑定127.0.0.1，配置登记允许读取的Trace和视图，HTTP不得接受任意磁盘路径。使用COOP/COEP，拒绝非本机Host和跨源读取。

GET /api/capabilities 提供版本与能力；GET /api/views/<id> 返回已登记视图和Trace身份；GET /api/captures/<id>/trace 只传输登记文件；/profiler/ 提供匹配版本的运行时；/open/<id> 是Markdown入口。配置文件只在启动时读取，不允许网页写配置。

浏览器核对完整Trace SHA，放入Wasm虚拟文件系统后启动原生main，不预编译Trace资源。每个已打开实例一次main；同Trace后续导航复用实例，切换Trace使用独立实例或明确重新加载，不在活跃Worker上覆盖文件。

原生导航桥接受FrameSet名称、Query帧索引和期望起止时间；原生返回实际显示号。可选线程ID/名称及CPU事件起止/名称用于交叉核对，失败不改变当前视图。目标轨道展开并滚动可见，其他轨道不删除。Job对象与GPU资源精确选择不在第一阶段能力声明中。

加载完成、后台完成、定位核对、布局就绪、导出成功分别记录。只有原生实际范围及轨道可见性稳定后导图。CPU等待/执行等分析数值继续由Query负责，已有负运行时间问题保留为限制，不用网页异常字段形成结论。

先运行服务合同失败用例；实现后运行服务测试及真实非1324录制验收。验收覆盖命名FrameSet、默认Frames、错误Trace/错误帧/错误范围、连续导航、缩放/平移/其他轨道/事件详情。不提交或合并分支，等待用户验收。
